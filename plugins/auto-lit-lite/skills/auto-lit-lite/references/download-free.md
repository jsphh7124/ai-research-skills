# 免費管道下載階梯

逐篇走以下階梯，成功即止。全程只用免費公開管道；授權邊界見 SKILL.md「設計定位與授權邊界」——付費牆內拿不到就標「需手動」，不硬闖。

## 階梯

1. **arXiv／預印本 DOI 直抓**：DOI 是 `10.48550/arXiv.<id>` 的，去掉 `10.48550/arXiv.` 前綴取得 arXiv id（新式如 `2408.01234`，可含版本號 `v2`；舊式含學科前綴如 `cs/0112017` 也直接沿用），`curl -L -o "<規則檔名>.pdf" https://arxiv.org/pdf/<id>` 抓（`-L` 跟隨轉址；輸出檔名直接用規則名，批次時切勿共用同一個輸出檔名）。PsyArXiv／OSF preprint 開 DOI 落地頁找「Download」按鈕的實際連結再抓，不要猜 URL 模板。命名以預印本頁實際作者序為準。
2. **Unpaywall API 查合法 OA 副本**（不需瀏覽器）：`https://api.unpaywall.org/v2/<DOI>?email=<聯絡email>`——email 用首次設定時使用者提供的真實信箱；DOI 含特殊字元（括號、`<>` 等）要先 URL-encode。回應的 `best_oa_location.url_for_pdf` 有值就 `curl -L` 抓。⚠️ Unpaywall 標 OA 不保證真抓得到（連結失效、機構典藏擋爬），抓回來一律驗檔（見下）。
3. **Google Scholar 直連**（低頻互動式，見 SKILL.md 授權邊界）：搜「"論文標題"」（加引號精確比對），看結果**右側**是否有 `[PDF]` 直連（出版社 OA、機構典藏、作者自存檔）。
   - 右側連結指向 `.pdf` 檔：點擊或導航即下載；落地後改規則名。
   - 落點來源要看：OA 出版頁、機構典藏、作者自存檔（RG、個人網頁）可抓；**來路不明的副本（課程講義站、第三方轉載）跳過標「需手動」**，不當作合法來源。
   - 指向 ResearchGate：導航過去，分頁停在 PDF 上時試同源 `fetch(location.href)` → blob → `a.download` 規則檔名一步到位；content script 進不去該分頁時（部分環境對 PDF 檢視器分頁限制不一），改「頂層導航＝原生附件下載」再改名。
   - 在校園網路內右側連結會更多（機構訂閱直連）——屬機構授權內的個人使用，維持小批次、遵守你機構的授權條款。
4. **ResearchGate 站內搜**：搜標題，看作者是否上傳全文（「Download full-text PDF」）。僅摘要頁或 request-only → 視為不可得，**不代使用者發 request**。
5. **出版商 OA 頁**：DOI 頁有 CC 授權標示的，直接從出版商頁面抓 PDF（文章頁找 PDF 連結，同源 fetch）。
6. **以上皆否 → 標「需手動」**，註明嘗試過的管道與失敗原因（paywall / 無 OA 副本 / 連結失效 / 授權不明），由使用者走機構圖書館（資料庫、館際合作）。

## 通用要領（實測經驗）

> 以下瀏覽器行為是在 Claude Code + Claude in Chrome 擴充功能環境下的實測結論（2026-08，macOS/Chrome）；不同版本或環境可能有差異，遇到不一致以現場實測為準。

- **驗 `%PDF` magic bytes 再入庫**：`blob.slice(0,8).text()` 開頭須為 `%PDF`（curl 抓的檔用 `head -c 5`）。content-type 標 pdf 但 body 是 HTML 的情況存在（轉跳頁、錯誤頁）。再看檔案大小是否合理（正常論文多在 200KB–5MB）。
- **fetch 成功≠檔案落地**：每篇下載後列出下載目錄驗證（目錄依瀏覽器設定，預設 `~/Downloads`），別只信 JS 回傳 OK。
- **per-tab 首次下載放行**：每個**新分頁**的第一次程式化下載會自動放行，同分頁第二次常被靜默擋下（reload 無效）。批次下載「每篇新分頁 → 導航 → 下載 → 關分頁」；或請使用者對該站點一次「允許自動下載多個檔案」（per-site 記憶，之後全自動）。
- **Chrome 視窗保持前景**：背景視窗的程式化下載可能被靜默卡成 pending（連 .crdownload 都沒有），回前景才一次湧出。
- **分頁正在顯示 PDF（內建檢視器）時 content script 可能進不去**：錯誤訊息看起來像網域權限問題，其實不是。改在 HTML 頁同源 fetch，或用「頂層導航＝原生附件下載」路徑。
- **驗證碼＝過量訊號，直接收手**：偵測到 Scholar reCAPTCHA／Cloudflare 驗證頁，就停止本輪對該站的自動查詢，剩餘篇目改走其他管道或標「需手動」。是否解驗證碼、何時繼續，由使用者自行決定；一律不程式化通過。
- **節流**：Scholar 連續查詢間隔 ≥10 秒防 captcha；同 domain 下載間隔 ≥1.5 秒。對掛 Cloudflare 的站，命令列 curl 通常被擋（實測經驗），優先走瀏覽器路徑。

## 誠實邊界

- 拿不到就是拿不到：「需手動」是正常結局，不是失敗。清單裡誠實標注比硬湊下載率重要。
- 不使用盜版鏡像站（Sci-Hub 等）；不引入自動化憑證工具或驗證碼 OCR——可能牴觸圖書館與網站使用條款，且憑證交給腳本有外洩風險。
- 下載的 PDF 供使用者個人研究使用，不再散布。
