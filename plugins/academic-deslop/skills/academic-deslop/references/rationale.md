# academic-deslop 規則的理由

執行本 skill 不需要讀這份。要修改「執行紀律」或 dash 規則、或規則的效果與預期不符時才讀。

- **兩階段（先列清單再改）**：實測基礎有兩點。純改寫（paraphrase）移除不掉痕跡，只是換位置擺；而編輯品質的瓶頸在「怎麼改」，不在「找得準不準」。先列清單能把找問題和改問題拆開。
- **逐組分開掃**：實測過注意力塌陷。LLM 拿到完整判讀指南後，理由會壓倒性集中在單一維度，其餘維度形同未掃。一次只給一組、每組重讀一次原文，才能讓各維度都被實際檢查到。
- **Dash 超額時不機械全刪**：把 dash 全部刪光本身就是可辨識的過度校正（見 SKILL.md 核心原則 7），比原本的密度問題更像 AI 修過的痕跡。
